# StamoTenti — Sources & Media Summary

## Scopo

Questo documento riassume il trattamento di fonti, citazioni, dataset e media.
Non sostituisce SOURCE-SPEC.md, CITATION-SPEC.md, DATASET-SPEC.md,
MEDIA-SPEC.md o LICENSE-SPEC.md.

## Fonti

Una fonte:

- possiede un'identità stabile;
- è definita una sola volta;
- può essere usata da più articoli;
- conserva i metadata verificabili;
- può avere DOI, ISBN, URL o altri identificativi.

L'assenza di un dato è preferibile a un dato inventato.

## Qualità

Autorevolezza e pertinenza sono distinte.

La fonte appropriata dipende dall'affermazione da sostenere.

Quando opportuno devono essere considerate fonti primarie, studi originali,
review, meta-analisi, testi accademici, fonti istituzionali e dataset.

## Accessibilità

Leggere, usare per ricerca, citare, pubblicare e redistribuire sono capacità
distinte.

Una fonte accessibile online non è automaticamente redistribuibile.

StamoTenti non deve aggirare paywall, DRM, licenze o restrizioni.

## Citazioni

La citazione collega una fonte a uno specifico utilizzo nell'articolo.

Può indicare una posizione precisa come pagina, sezione, timestamp o altra
unità pertinente.

La bibliografia deve essere derivata dalle fonti realmente utilizzate.

## Dataset

Il dataset è un'entità distinta dal file.

Devono essere conservati, quando rilevanti:

- provenienza;
- versione;
- licenza;
- identificatori;
- metodologia;
- trasformazioni;
- relazione con pubblicazioni.

## Media

I media includono immagini, PDF, EPUB, audio, video e altri file.

Devono essere classificati almeno come:

- public;
- private;
- controlled;
- pending_review.

La possibilità tecnica di accedere a un file non costituisce autorizzazione
alla distribuzione.

## Storage

GitHub è principalmente destinato a codice, Markdown, configurazioni,
template e metadata appropriati.

I media voluminosi o privati devono utilizzare storage appropriato.

Zenodo può essere utilizzato selettivamente per archiviazione e citabilità
di risorse pubblicabili, senza diventare lo storage operativo generale.

## Licenze

La licenza dipende dall'oggetto.

Codice, documentazione, articoli, dataset, media, font e dipendenze possono
avere regimi differenti.

Le licenze non devono essere inventate.
