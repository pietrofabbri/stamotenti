# StamoTenti — Dependency Map

## Scopo

Questo documento mappa le dipendenze documentali rilevate nel repository.
È una mappa di orientamento e manutenzione, non una fonte normativa.
Le regole effettive restano definite dai documenti fondativi e dalle SPEC.

## Principi

- la mappa descrive relazioni, non introduce autorità;
- un riferimento a una SPEC non modifica la gerarchia delle specifiche;
- i riferimenti mancanti devono essere segnalati;
- le dipendenze tecniche del codice non sono incluse automaticamente;
- la mappa può essere rigenerata quando cambiano i documenti.

## Livelli logici

```text
TO-BE.md
  ↓
PROJECT-MAP.md
  ↓
SUMMARY/*.md
  ↓
SPEC
  ↓
documenti tecnici
  ↓
codice
```

Questo schema è orientativo. Le singole SPEC possono avere dipendenze locali differenti senza costituire necessariamente una gerarchia globale.
